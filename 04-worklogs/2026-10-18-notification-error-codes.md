- 작성일: 2026-10-18

- 상태: 검토 대기
- 영향 범위: 공통 / 프론트엔드 / 백엔드

## 목적

사용자 알림 N01~N03의 오류 표를 공통 API 명세와 현재 백엔드 응답에 맞춘다.

## 한 일

- 사용자 확인에 따라 오류 코드를 `USER_CONTEXT_REQUIRED` → `USER-003`, `USER_CONTEXT_INVALID` → `USER-002`, `USER_MEMBERSHIP_MISMATCH` → `USER-006`으로 정정했다.
- 필수 헤더 누락 조건에 `X-User-ID`와 함께 `X-User-Role`을 명시했다.
- HTTP 상태와 API 경로·DTO는 변경하지 않았다.

## 확인된 내용

- [공통 API 오류](../05-api/common.md#오류)는 이미 번호형 코드를 현행 코드로 명시한다.
- 백엔드 오류 정의와 기존 알림 테스트도 번호형 코드를 사용한다. 사전 조사에서 알림 컨트롤러 테스트가 통과했다.
- 프론트엔드 원격 `dev`의 오류 메시지 처리는 번호형 코드를 지원하지만 사용자 알림 목업과 테스트에는 이전 코드가 남아 있다. 프론트엔드 수정은 사용자 설명에 따라 팀원이 담당하며 이번 작업에 포함하지 않았다.
- 문서 변경은 diff·공백·상대 링크를 검증하며 애플리케이션 테스트·빌드는 재실행하지 않는다.
