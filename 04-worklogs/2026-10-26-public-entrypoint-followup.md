# API 색인의 도메인별 상태와 누락 항목 정리

## 목적

공개 진입점 후속 정리에서 API 색인의 오래된 일괄 상태와 누락 ID를 정리하고, 계약 채택·구현·배포·프론트엔드 연동의 확인 위치를 구분한다.

## 수행 내용

- [API 색인](../05-api/README.md)의 일괄 검토 대기 문구를 도메인별 상태 안내로 바꿨다.
- 출석 AP05·AP06, 미션 AM05, 응모권 AO09와 게임별 연동 문서 링크를 보완했다.
- 최초 발표의 PR 대기 문구를 없애고 추첨 문서의 코드 대조·적용 상태를 참조하도록 정리했다.
- AG01~AG03의 제안 기록과 프론트엔드 문서의 제공 범위 제외 기록을 구분했다.
- 색인의 백엔드 저장소 링크를 Uplus-GETDDO 조직명으로 통일했다. API 계약·정책·경로·본문은 변경하지 않았다.

## 확인한 사실

- 로컬 `main`과 `origin/main`의 이력 차이가 없는 상태에서 작업을 시작했다. 원격 서버의 최신 상태를 새로 조회한 것은 아니다.
- [출석](../05-api/attendance.md), [미션](../05-api/mission.md), [응모권](../05-api/ticket.md) 원문에 AP05·AP06, AM05, AO09의 계약 표와 구현 반영 상태가 있다.
- [추첨·결과](../05-api/drawing.md)의 코드 대조 기준과 적용 상태 절은 최초 발표 PR #108의 2026-10-17 병합·dev 배포 및 2026-10-20 경로 확인을 기록한다. 이번 작업에서 배포를 다시 확인하지 않았다.
- [게임 API](../05-api/game.md)는 AG01~AG03을 미채택 제안으로 남긴다. [프론트엔드 현재 범위](https://github.com/Uplus-GETDDO/getddo-fe/blob/dev/docs/CONTEXT.md)와 [연동 현황](https://github.com/Uplus-GETDDO/getddo-fe/blob/dev/docs/backend-integration-status.md)의 로컬 문서는 2026-10-22 담당자 답변에 따른 관리자 게임·보상 조건 관리 제공 범위 제외를 기록한다.
- 공통·이벤트·관리자 일별 집계·어뷰징 등 원문에 남은 검토 대기·미확인 상태는 색인에서 새로 확정하지 않았다.
- 변경 문서 두 개의 상대 링크 29개가 모두 존재하며 `git diff --check`를 통과했다. 초기 Prettier 검사에서 API 색인 표 정렬 경고를 확인한 뒤 사용자가 승인한 문서 수정 범위에서 정렬을 맞췄다. 현재 두 문서의 Prettier 검사가 통과했다.

## 후속

- 각 API 담당자가 개별 계약과 구현·배포 상태를 갱신하면 색인의 안내도 함께 대조한다.
- 프론트엔드 연동·실측과 배포 검증은 코드 저장소 기록에서 관리한다. 이번 작업은 문서 원문 대조와 상대 링크 검증만 수행한다.
- 커밋·원격 반영은 전체 후속 정리의 통합 단계에서 수행한다.

## 미결정 사항

- 새로운 공용 정책이나 API 계약 결정은 없다. 기존 후속은 [미결정 사항](../00-requirements/pending-decisions.md)을 따른다.
- 관리자 게임 원문 제안의 정리와 개별 API의 오래된 구현·배포 표기 갱신은 이번 색인 변경 범위에 포함하지 않았다.
