# GD-314 추첨 공개 오류·실행 감사 표시·장애 대응 기준 정리

- 상태: 검토 대기 — Codex 작성, 담당자 확인 전
- 작성일: 2026-10-23
- 관련: [GD-314](https://ureca4.atlassian.net/browse/GD-314)

## 목적

사용자가 확정한 공개 오류 문구, 실행 감사 화면 표시와 장애 대응 기준을 공용 원본에 반영한다.

## 변경 전·후

- 변경 전: 공통 공개 오류 문구 정렬과 복구·취소 판단을 담당자 후속으로 남겼다. 감사 원문의 화면 표시 기준은 명시하지 않았다.
- 변경 후: [추첨 규칙](../02-domain/drawing.md#실패-복구와-관리자-판단), [API의 감사 표시 계약](../05-api/drawing.md#실행-감사-표시-계약--gd-314)과 오류 문구를 정리하고 [미결정 사항](../00-requirements/pending-decisions.md)의 해당 후속 문구를 결정 완료로 연결했다.

## 확인한 사실과 영향

- 최신 원격 백엔드 dev 4086ff67의 오류 enum·실행 실패 분류·예약·감사 호출부를 대조했다. 제한 재시도·관리자 대기·동일 실행 재개는 기존 구현을 재사용한다.
- 백엔드 응답·감사 저장값·권한·상태 전환과 DB 구조는 유지한다. 프론트는 승인된 화면 표시 변경을 별도로 적용해야 한다.
- 문서 확정과 백엔드 코드 PR·배포·프론트 적용을 구분한다. 이번 문서 작업에서 새 기능의 동작 검증이나 운영 적용 완료를 주장하지 않는다.

## 검증·후속

- 신규 상대 링크·앵커 10건, 코드 블록과 공백·diff 및 미결정 항목의 참조를 확인했다.
- 백엔드 오류 문구·회귀 테스트와 내부 운영 문서는 [GD-314 PR #165](https://github.com/Uplus-GETDDO/getddo-be/pull/165)에서 검토한다. 프론트 표시 적용과 실제 배포는 별도 확인한다.
