# 이름 필드·플래티넘 구현 현황 표기 갱신

- 상태: 검토 대기 — Claude 작성, 담당자 확인 전
- 작성일: 2026-10-23
- 관련: [GD-284](https://ureca4.atlassian.net/browse/GD-284), GD-228·GD-229·GD-230

## 목적

백엔드에 병합된 변경을 응모권·응모·출석·미션 API 문서의 상태 표기에 맞춘다.

## 변경 전·후

- 변경 전: 관리자 응답의 이름 필드를 "구현 예정", 플래티넘을 "적용 시점과 구현·연동 검증은 후속"으로 적었다.
- 변경 후: 이름 필드는 구현 완료(PR #153, 2026-10-22 병합·`main` 반영)로, 플래티넘은 구현과 지급 활성화 병합으로 적었다. 계약 내용과 업무 정책은 바꾸지 않았다.

## 확인한 사실

- `dev`의 응답 DTO에 `createdByName`(출석 정책·미션)과 `userName`(응모·응모권 정합성)이 있다.
- 플래티넘 지급 확률은 설정값이고 기본이 2bp다. 개발 서버 설정 파일에는 덮어쓴 값이 없었다(2026-10-22 읽기 전용 확인). 그 시점 플래티넘 응모권은 0장이었다.
- 반영 문서: [응모 API](../05-api/entry.md#2026-10-17-플래티넘-등급-계약-반영), [응모권 API](../05-api/ticket.md), [미션 API](../05-api/mission.md), [출석 API](../05-api/attendance.md), [미결정 사항](../00-requirements/pending-decisions.md#등급-응모권).

## 후속

- 플래티넘 지급·응모·추첨의 실서버 동작과 프론트엔드 연동 검증은 아직이다.
- 같은 이름 필드의 "구현 예정" 표기가 [공통 계약](../05-api/common.md), [추첨 API](../05-api/drawing.md), [알림 API](../05-api/notification.md)에 남아 있다. 각 담당자가 확인한다.
- [어뷰징 API](../05-api/abuse.md)의 "구현·배포는 미확인" 표기는 AR01·AR02와 GD-144 병합 뒤 담당자가 갱신한다.
