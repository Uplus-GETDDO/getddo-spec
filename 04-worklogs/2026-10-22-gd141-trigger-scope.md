# GD-141 evidence 세부 계약과 대표 근거 확정

- 상태: 검토 대기 — Codex 작성, 담당자 확인 전
- 작성일: 2026-10-22
- 관련: GD-141, [BE PR #149](https://github.com/Uplus-GETDDO/getddo-be/pull/149)

## 목적

BE 설계안으로 기록돼 있던 동시 기준 대표 선택과 제안 상태의 evidence 세부 계약을 사용자 결정에 따라 공용 API 원본에 반영한다.

## 변경 전·후

- 변경 전: 두 기준이 동시에 충족될 때 대표 triggerScope 선택과 evidence 세부 필드명·타입은 후속이었다.
- 변경 후: 2026-10-22 사용자 결정을 [어뷰징 조회 API의 evidence 계약](../05-api/abuse.md#abusecasedetail)에 반영했다. 미결정 항목에서도 대표 선택과 세부 필드 채택을 결정 완료로 갱신하고 ADR-027의 후속 설명을 맞췄다. ADR 자체의 제안 상태는 변경하지 않았다.

## 영향

- FE: 동시 충족에도 단일 범위의 근거를 표시하며 두 범위 배열을 새로 요구하지 않는다.
- BE: 차단·이력은 한 건이며 원본 API 계약에 맞춰 대표 근거를 매핑한다.
- 사용자 응모 차단 시간·집계 기준·응답 코드는 변경하지 않는다.

## 검증·다음 할 일

- 해당 API·미결정 문서는 수정 전 원격 main과 로컬 내용이 같음을 확인했다. 다른 원격 문서 변경과 이번 변경을 함께 보존하고 기존 미추적 작업은 공유 대상에서 제외한다.
- 문서 diff·JSON 예시·관련 상대 링크를 검증했다. 런타임 코드·DB·API를 실행한 검증은 아니다.
- evidence 세부 JSON 필드명·타입은 사용자 결정으로 기존 제안을 채택했다. 오류 번호·구현·배포 후속은 유지한다.
- 공유 대상: spec main의 API·미결정 사항·관련 ADR 설명·작업 기록. 런타임 코드·구현 티켓 완료 처리는 포함하지 않는다.
