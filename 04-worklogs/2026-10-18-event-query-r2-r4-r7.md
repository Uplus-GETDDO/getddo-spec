# 작업 기록: 이벤트 조회 R2·R4·R7 공용 계약 반영

- 작성일: 2026-10-18 (KST)
- 관련 이슈 / PR: [GD-226](https://ureca4.atlassian.net/browse/GD-226), [BE PR #124](https://github.com/Uplus-GETDDO/getddo-be/pull/124)
- 상태: 완료
- 영향 범위: 공통 / 프론트엔드 / 백엔드

## 목적

사용자가 요청한 관리자 검색 확장(R2), 내 응모 여부(R7), 기본 이벤트·겟또타임 구분(R4)을 공용 명세에 반영한다.

## 한 일

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| R2 | AE01에 정렬·가중치·등록일 조건이 없음 | `sort`, `weightingEnabled`, `createdFrom`, `createdTo`의 타입·기본값·날짜 경계·조건 결합·오류를 명시 |
| R7 | 응모 문서에 설명만 있고 EventSummary 필드에 없음 | 사용자 목록에 `myEntered:boolean`을 명시하고 상세·관리자 응답에서는 제외. 응모 문서는 이벤트 계약을 연결 |
| R4 | 화면 명칭과 eventType의 대응 설명이 없음 | 기본 이벤트는 `NO_TICKET`, 겟또타임은 `TICKET` 전체임을 명시하고 공통 용어에 추가 |

## 확인된 내용

- spec `main`을 `24b914a`까지 pull한 뒤 변경했다.
- BE `origin/dev`의 GD-226 병합 커밋 `0f7a0864e60473aae02b0771d58b00f2f722e521`에서 요청 DTO·조회 서비스·정렬·저장소·응답 DTO를 대조했다.
- 등록일 검색과 기존 모집 기간 검색은 구분하며 함께 지정하면 AND로 적용한다. 두 날짜 범위 모두 KST 날짜 양끝을 포함한다.
- `myEntered`는 정상 접수 이력이며 추가 응모 자격이나 당첨 여부가 아니다. 취소·반환 후에도 기록에 따라 유지한다.
- 프론트엔드는 위 파라미터와 목록 필드를 사용하고 화면 분류에 기존 `eventType`을 사용한다. BE 배포와 FE 연동 완료 여부를 이번 문서 변경으로 확정하지 않는다.
