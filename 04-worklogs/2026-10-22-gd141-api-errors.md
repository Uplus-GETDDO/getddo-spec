# GD-141 관리자 차단 조회 오류 계약 확정

- 상태: 검토 대기 — Codex 작성, 담당자 확인 전
- 작성일: 2026-10-22
- 관련: GD-141, 후속 구현 GD-144

## 목적

FE가 AR01/AR02의 업무 오류와 기존 공통 오류를 구분해 처리할 수 있도록 사용자 승인 내용을 공용 API 원본에 반영한다.

## 변경 전·후

- 변경 전: 관리자 권한 거절과 상세 없음의 업무 오류 번호는 미확정이었다.
- 변경 후: [조회 오류 계약](../05-api/abuse.md#조회-오류-계약--ar01ar02)에 두 업무 오류·공개 메시지와 공통 오류 재사용 기준을 확정했다. 관련 API 표·미결정 사항·ADR-027의 후속 설명도 맞췄다.
- 목록 결과 없음·차단 만료는 정상 조회로 구분하고, 업무 상세 없음과 경로 미구현 404를 구분했다.

## 확인한 사실과 영향

- 수정 전 최신 BE dev·main의 api/core/storage/docs와 spec main에서 제안한 두 코드가 이미 사용 중이지 않음을 확인했다.
- 공통 오류와 사용자 문맥의 기존 상태·코드·메시지는 변경하지 않는다.
- FE는 업무 오류 분기와 공통 오류 처리를 계약에 맞출 수 있다. BE는 GD-144에서 이를 구현해야 하며 이번 명세 반영이 API 구현·배포 완료를 의미하지 않는다.

## 검증·후속

- 문서 diff·JSON 예시·관련 상대 링크와 앵커 검증을 통과했다.
- 런타임 코드를 변경하지 않으며 실제 API·DB·배포 검증은 수행하지 않는다.
- 확정된 계약의 코드 구현·배포와 FE 실측은 후속이다.
