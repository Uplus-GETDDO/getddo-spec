# API 계약

- 상태: 도메인별 채택·구현·배포 상태는 아래 안내와 각 문서의 개별 계약 절을 따른다.
- 기준: [확정 요구사항](../00-requirements/functional-requirements.md), [구현 범위](../00-requirements/scope.md), [도메인 규칙](../02-domain/README.md)

프론트엔드와 백엔드가 함께 사용하는 HTTP 요청·응답 계약이다. 계약 채택, 코드 구현·병합, 서버 배포, 프론트엔드 연동·실측은 서로 다른 상태다. 각 문서의 상태와 개별 계약 절에 적힌 범위·시점을 확인한다. 개별 확정이 표시되지 않은 경로·메서드·DTO·업무 오류 코드는 담당자 확인 전 제안이며, 확정된 요구사항·도메인 규칙과 충돌하면 해당 기준 문서를 우선한다. 별도 기재가 없으면 경로는 [공통 계약](common.md)의 `/api/v1` 접두사를 생략한다.

게임별 연동 기준은 [글자색깔 맞추기](game-color-word-draft.md), [타꼬런](game-takko-run-draft.md), [타꼬 타이밍 맞추기](game-takko-timing-draft.md), [타꼬 주문](game-takko-order-draft.md)을 따른다. 관리자 게임 AG01~AG03은 API 원문에 제안으로 남아 있으나, [프론트엔드 현재 범위](https://github.com/Uplus-GETDDO/getddo-fe/blob/dev/docs/CONTEXT.md)와 [연동 현황](https://github.com/Uplus-GETDDO/getddo-fe/blob/dev/docs/backend-integration-status.md)은 2026-10-22 담당자 확인에 따른 제공 범위 제외를 기록한다. 원문의 제안을 현재 제공 기능이나 채택 계약으로 해석하지 않는다.

DB 대응, 저장 방식, 내부 처리와 구현 검증 항목은 [백엔드 API 문서](https://github.com/Uplus-GETDDO/getddo-be/tree/dev/docs/02-api)와 [DB 문서](https://github.com/Uplus-GETDDO/getddo-be/tree/dev/docs/03-database)에서 관리한다. 프론트엔드 연동·배포 실측은 위 연동 현황에서 별도로 확인하며, 색인이 개별 문서의 미확인 상태를 일괄 해소하지 않는다. 담당자 판단이 필요한 도메인 정책은 [미결정 사항](../00-requirements/pending-decisions.md)을 따른다.
